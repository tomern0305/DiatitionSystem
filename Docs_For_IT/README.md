## סקירה כללית של המערכת

המערכת בנויה בשלוש שכבות:

```
┌──────────────────────┐
│  Client (React SPA)  │  דפדפן — Vite + TypeScript + Tailwind
└──────────┬───────────┘
           │ HTTPS / REST (JSON)
┌──────────▼───────────┐
│  Server (Flask API)  │  Python — REST API בלבד, ללא רינדור דפים
└──────────┬───────────┘
           │ SQL
┌──────────▼───────────┐
│  PostgreSQL          │  כולל תוסף pgvector לחיפוש סמנטי
│  + Supabase Storage  │  אחסון תמונות המוצרים
└──────────────────────┘
```

**שירותים חיצוניים:**

| שירות | תפקיד | האם חובה |
|-------|-------|-----------|
| Supabase Storage | אחסון תמונות המוצרים | כן — השרת לא עולה בלי המפתחות |
| OpenAI API | יצירת embeddings לחיפוש בשפה חופשית | לא — ניתן לכבות דרך `AI_ENABLED=false` |
| Vercel | אירוח השרת והלקוח | לא — אפשר לארח בכל מקום |

## נקודות תשומת לב מיידיות

הפריטים הבאים אותרו בקוד ודורשים החלטה של צוות ה-IT לפני עלייה לסביבת ייצור.
פירוט מלא בכל אחד מהמסמכים.

1. **משתמש ברירת מחדל `admin` / `admin`** נוצר אוטומטית בהפעלה ראשונה כשטבלת המשתמשים ריקה (`Server/app.py`). יש לשנות את הסיסמה מיד — המערכת אמנם מכריחה החלפה בכניסה הראשונה.
2. **`JWT_SECRET` אינו מוגדר בקובץ ה-`.env` הקיים.** בהיעדרו הקוד נופל לערך קבוע שכתוב בקוד המקור. חובה להגדיר מפתח אקראי בייצור, אחרת ניתן לזייף טוקנים.
3. **סיסמת בסיס הנתונים המקומי כתובה בגלוי** בקובץ `Data Base/docker-compose.yml` שנמצא בגיט. זה מקובל לסביבת פיתוח מקומית בלבד.
4. **רוב נקודות ה-API אינן מוגנות באימות.** ראו את הטבלה המלאה ב-[01-server.md](01-server.md).
5. **`CORS(app)` פתוח לכל מקור.** ראו [01-server.md](01-server.md).
6. **אין מנגנון מיגרציות מסודר** (Alembic/Flask-Migrate). שינויי סכימה מבוצעים בשלוש דרכים אד-הוק. ראו [03-database.md](03-database.md).
